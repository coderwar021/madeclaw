Getting started

下载后怎么用

  1. 安装 / 打开 — macOS：打开 DMG，将 MadeClaw.app 拖入「应用程序」后启动。 Windows：运行对应 Setup.exe。
  2. Gateway / Control UI — App 会拉起本机 Gateway；在 App 或 Control UI 完成引导。状态与端口以 App / 本机状态页为准（MadeClaw 配置档案）。
  3. 注册账号 — 打开 madeclaw.up.railway.app 注册，登录后在 账号页 复制稳定 userId，写入 App 插件 / MadeClaw 配置（与充值、扣费同一 ID）。
  4. 模型与密钥 — 在 App 内选择模型（见 模型列表）。可填 MadeAPI Key；或充值后走本站独立余额。 自备非 MadeAPI 接口时可跳过余额扣费。
  5. 充值对齐用量 — 余额不足时从 App「充值」或本站 /recharge 支付；Webhook 入账后，App madeclaw_balance 与本站账本一致。用量见 /usage。
