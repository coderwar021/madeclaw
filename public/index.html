下载后怎么用

  1. 从 下载页 获取 macOS DMG（或 Windows 安装包），打开 MadeClaw.app。
  2. 在本站 注册 / 登录，记下账号页显示的 userId。
  3. App 内填 MadeAPI Key，或充值后用本站余额；模型在 App / Control UI 选择。
  4. 余额不足时打开 充值；支付成功后与 App 扣费同一 userId。
