Features

功能介绍

MadeAPI 将执行留在桌面，将账号与结算留在官网。开箱连接 MadeAPI 官网服务，余额与模型 API 钱包严格隔离。

  • App + Control UI

    桌面客户端负责日常对话与执行；Control UI / Gateway 管理会话、模型与插件状态。

  • 独立余额

    充值与扣费只写入本站账本。同一 userId 贯穿支付与运行，不与第三方钱包混用。

  • 安全充值

    通过本站 充值 或 App 内链接进入收银台；支付成功后由 Webhook 入账。登录后自动绑定你的 userId。

  • Token 用量

    客户端上报用量；官网 用量页 与账号页可查看汇总。

  • 消息下传

    运营可通过 API 下发消息，App 轮询收取，失败也有可见结果。

  • 开箱即用

    默认计费与支付入口指向 MadeAPI 官网；服务令牌与站点一致，减少手工配置。
