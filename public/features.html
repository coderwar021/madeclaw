功能介绍

MadeClaw 把「干活」留在桌面，「账号与钱」留在本站。开箱连 Railway 官网，不跟 MadeAPI 钱包混账。

  • App + Control UI 双端

    桌面 App 日常对话与执行；Control UI / Gateway 管会话、模型与插件状态。

  • 独立余额

    充值与扣费只写本站账本（creditsMadeApiWallet: false）。同一 userId 贯穿支付与运行。

  • 充值

    App 内打开充值链接或本站 /recharge → Waffo 收银台 → Webhook 入账。登录后自动绑定你的 userId。

  • Token 用量统计

    插件上报用量；官网 /usage 与账号页可查看汇总。

  • 消息下传 inbox

    运营可经 API 下发消息，App 轮询收取，失败也有可见结果。

  • 开箱连本站

    默认 billingBaseUrl / payBaseUrl 指向 madeclaw.up.railway.app；OOB serviceToken 与站点一致。
